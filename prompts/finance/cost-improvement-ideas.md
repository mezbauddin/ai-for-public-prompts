# Generate cost improvement ideas for a service line

**For:** Finance  
**Tool:** Copilot Chat  
**Task:** Plan

## Prompt

```text
I run finance for {service line, e.g. outpatient ophthalmology} in a UK trust. Suggest 10 cost improvement ideas. For each: one-line description, rough size of saving (small, medium, large), main risk, and what evidence I would need to make the case. UK English. Avoid generic ideas like "go paperless".
```

## Why it works

The "avoid generic" line genuinely changes the output. Asking for risk and evidence stops it pitching ideas the board would laugh at.

## Watch out

Treat it as a brainstorm. None of these are vetted against your data.

## Example output

Made-up data, for illustration only.

```text
1. Shift stable follow-ups to virtual (medium saving; risk: digital exclusion; evidence: DNA rates by mode).
2. Pool a shared injection list across consultants (small; risk: training; evidence: current per-list utilisation).
```
