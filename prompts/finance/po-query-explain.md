# Explain a purchase order query to a budget holder

**For:** Finance  
**Tool:** Copilot Chat  
**Task:** Translate

## Prompt

```text
Explain this purchase order or invoice query to a non-finance budget holder. UK English. Plain language. Tell them what the issue is, why it is holding up payment, and the one thing you need them to do to release it. Under 120 words.

Query:
{paste}
```

## Why it works

Budget holders ignore finance jargon. Naming the single action they need to take is what actually gets the PO released.

## Watch out

Make sure it has not softened a hard requirement. If approval is mandatory, the email needs to say so plainly.
