# First draft of a DPIA for a low-risk tool

**For:** Information governance  
**Tool:** Copilot Chat  
**Task:** Draft

## Prompt

```text
Draft a Data Protection Impact Assessment for {tool name}. Follow the ICO template structure. Sections: Description of processing, Necessity and proportionality, Risks (use a risk-likelihood-impact table), Measures to mitigate. UK English. Keep each section to under 250 words. Flag any sections where you would need information from the supplier with [SUPPLIER INPUT].
```

## Why it works

The [SUPPLIER INPUT] flag turns the document into a list of questions for procurement, which is the part of DPIA work that always slips.

## Watch out

A DPIA is a legal record. Treat any LLM output as a first draft only. The signatures at the bottom carry weight.
