# Turn an executive inbox into a daily action list

**For:** Executive support  
**Tool:** Microsoft 365 Copilot  
**Task:** Analyse

## Prompt

```text
Go through my director's unread emails from the last two days. For each, give: who from, one-line summary, and a recommended action from this list: needs them today, I can handle, needs a reply this week, FYI only, decline politely. Group by recommended action with "needs them today" at the top. Flag anything that looks time sensitive or from a named VIP.
```

## Why it works

Splitting "I can handle" from "needs them today" is the core of the EA job, and a fixed action list keeps the triage consistent. Flagging VIPs stops the one email that matters slipping down the pile.

## Watch out

It only sees mailboxes the account can access. Check delegate access is set up correctly before trusting the sweep, and never let it auto-send.
