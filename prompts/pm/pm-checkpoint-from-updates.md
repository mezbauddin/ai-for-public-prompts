# Build a checkpoint report from team updates

**For:** Project and programme managers  
**Tool:** Microsoft 365 Copilot  
**Task:** Summarise

## Prompt

```text
Turn the team's updates below into a PRINCE2 checkpoint report for the project manager. UK English. Cover: progress against the work package this period, products completed, products planned for next period, issues and risks raised, and how much tolerance is left. Keep it tight. Flag anything that looks like it will breach tolerance with [TOLERANCE].

Updates:
{paste}
```

## Why it works

Pulling scattered team updates into one checkpoint with a tolerance view is what lets a PM manage by exception. The [TOLERANCE] flag surfaces trouble before it becomes an exception.

## Watch out

Confirm the tolerance figures with the team lead. The model can only flag what the updates actually mention.
